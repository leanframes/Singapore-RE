# Images Directory

Place your property images here:

## Required Images

- `hero.jpg` - Main hero image (1920x1080 recommended)
- `og-image.jpg` - Open Graph image for social sharing (1200x630)
- `favicon.ico` - Site favicon

## Gallery Images

Place in `/gallery/` subdirectory:
- `exterior-1.jpg`
- `interior-1.jpg`
- `interior-2.jpg`
- `pool.jpg`
- `view.jpg`

## Recommendations

- Use high-quality, professional photography
- Images should be blurred or obscured for OG/social preview
- Compress images for web performance
- Recommended format: WebP or optimized JPEG
